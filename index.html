ขั้นตอน (ทำทีละข้อ)

  1. กดปุ่ม คัดลอก ของไฟล์ด้านล่าง
  2. เปิดชีทระบบ → เมนู ส่วนขยาย → Apps Script แล้วเปิดไฟล์ชื่อเดียวกันทางซ้าย
  3. กดคลิกในกล่องโค้ด → Ctrl+A (เลือกทั้งหมด) → Ctrl+V (วางทับ) → กดบันทึก 💾
  4. ทำซ้ำกับอีกไฟล์ให้ครบ (ไฟล์ dbg.gs ไม่ต้องแตะ)
  5. กด ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เลือก เวอร์ชันใหม่ → ทำให้ใช้งานได้ (ลิงก์เดิมใช้ต่อได้)
